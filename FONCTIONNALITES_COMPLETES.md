- **React** : 18.x (Hooks, Context API)

### État et Contextes
- **AuthContext** : Authentification
- **BNBContext** : Données métier (propriétés, voyageurs, réservations)

- **CustomizationContext** : Personnalisation de l'interface
- **NotificationContext** : Notifications temps réel

### Build & Dev Tools
- **npm** : Gestion des packages
- **Turbopack** : Bundler ultra-rapide
- **ESLint** : Linting
- **TypeScript Compiler** : Vérification de types
